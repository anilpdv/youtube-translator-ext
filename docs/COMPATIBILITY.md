# Compatibility matrix

The qualification target is desktop Chromium: Chrome stable, Edge stable, and
Brave when explicitly supported, on Windows, macOS, and Linux. Scenarios are
standard YouTube watch pages in normal, theater, fullscreen, autoplay,
back/forward, and playlist navigation modes.

Stable V1 excludes Shorts, embedded players, livestreams, and videos without
captions. Live pages are not used as the sole CI fixture; deterministic local
fixtures remain authoritative.
