# Release checklist

- [ ] Stable feature flags validated
- [ ] Full compile, unit, contract, integration, security, and build gates pass
- [ ] Manifest permissions and package contents verified
- [ ] Fresh-install, upgrade, cache migration, deletion, and rollback tested
- [ ] Compatibility matrix completed
- [ ] Beta blockers triaged and resolved
- [ ] Privacy, security, and store listing reviewed
- [ ] Approved package checksum and release report archived
